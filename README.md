## ⚡ Overview & Vision

**Quantam Gaming** is a premier digital esports organization, championship tournament host, and interactive game technology ecosystem. This web platform serves as the central command hub for competitive players, esports teams, creators, and commercial partners worldwide.

Built from the ground up with high-performance Vanilla web technologies, cutting-edge cyber-gaming aesthetics, glassmorphism UI, real-time quantum particle physics on HTML5 Canvas, and a dual-tier **Primary and Alternative Communications Matrix**.

## 🛠️ Tech Stack & Architecture

- **Markup:** Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) with OpenGraph, Twitter Cards, and SEO metadata.
- **Styling:** Custom Vanilla CSS3 using custom CSS variables (Design System Tokens), responsive CSS Grid, Flexbox, and backdrop-filter glassmorphism.
- **Scripts:** Modular Vanilla JavaScript (`app.js`) handling particle physics, animated numbers, tabbed filtering, form validation, and modal dialogue control.
- **Typography:** Google Fonts:
  - `Orbitron` — Futuristic, cyber-styled headings and gaming badges.
  - `Plus Jakarta Sans` — Clean, highly readable body typography.
  - `JetBrains Mono` — Code blocks, telemetry indicators, and server tick stats.

## 🚀 Getting Started

### Option 1: Direct Browser Launch
Simply double-click or open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Brave, Safari).

### Option 2: Local HTTP Server (Python)
```bash
# Python 3
python -m http.server 8080
```
Then navigate to `http://localhost:8080`.

### Option 3: Local HTTP Server (Node.js / npx)
```bash
npx serve .
# or
npx http-server .
```
